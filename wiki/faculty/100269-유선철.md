## 학회발표
수중 이미징 소나와 단안 카메라의 컨투어 융합과 기지 물체 CAD 데이터 활용을 통한 3차원 매핑 정밀도 향상 방법 (2025년 한국수중수상로봇기술연구회 추계학술대회); 이미지소나 정보의 주파수-공간 도메인 융합 기법을 활용한 수중환경에서의 강건한 로봇 위치인식 방법 (2025년 한국수중수상로봇기술연구회 추계학술대회); 소나 및 광학 센서 융합 기반 수중 다중 로봇 맵핑 기법 (2025년 한국수중수상로봇기술연구회 춘계학술대회); 자율 무인 잠수정을 위한 소나 및 광학 정보 융합 기반의 3차원 수중 지도 생성 기법 (2025년 한국수중수상로봇기술연구회 춘계학술대회); Entropy Map Based Active Seabed Scanning Method Using Underwater Image Sonar for AUV (2025 IEEE Underwater Technology, UT 2025); 수중 구조물의 미세 균열 탐지를 위한 레이저와 광학 비전 기반 융합 센싱 시스템 (KRoC 2025); 수중로봇의 이미징 소나를 활용한 엔트로피 맵 기반 최적 경로계획 (KRoC 2025); 수중 전기장 랜드마크를 이용한 수중로봇의 위치추정 방법 (KRoC 2025); 수중 플래시 마커를 사용한 수중 로봇의 위치 추정 방법 (KRoC 2025); 수중 로봇의 다중 소나 정보를 융합한 수중 3차원 지도 정밀도 향상 방법 (KRoC 2025); 수중 구조물의 고정밀 고속 안전검사를 위한 수중로봇의 다관절 스캐닝 시스템 (KRoC 2025); Development of a remotely operated robot system for movement in narrow areas based on workspace characteristics (2025 IEEE/SICE International Symposium on System Integration, SII 2025); 극한작업 무인화를 위한 한수원 -포스텍 로봇연구센터의 소개와 전망- (2024 한국안전학회 추계학술대회); Visual SLAM-Based 3D Path Planning Method of UUV for Enhancement of 3D Reconstruction Using Photogrammetry (2024 24th International Conference on Control, Automation and Systems (ICCAS 2024)); Development of Bioinspired Multimodal Underwater Robot “HERO-BLUE” for Walking, Swimming, and Crawling (IROS 2024); Optimal Control of Dual Buoyancy Controllers for Underwater Walking on Various Slopes (2024 IEEE OES AUV); 센서 융합 기반 수중 정밀탐사를 위한 동적 경로 생성 방법 (2024 제39회 제어로봇시스템학회 학술대회); 복수의 수중 로봇을 이용한 센서 융합 기반 정밀 수중 맵핑기법 (2024 제39회 제어로봇시스템학회 학술대회); Effective Sonar Image Segmentation Method based on Beam Analysis for Object Recognition of AUV (OCEANS 2024 SINGAPORE); 수중로봇의 이미징 소나와 비전의 센서융합을 통한 물체 인식방법(Underwater Sonar and Visual Information Fusion for Object Recognition of Underwater Robots) (KRoC 2024 (제19회 한국로봇종합학술대회)); 수중 소나 이미지의 주파수 분석을 통한 수중 로봇의 위치 추정 방법(Localization of Autonomous Underwater Vehicle through Frequency Analysis of Underwater Sonar Images) (KRoC 2024 (제19회 한국로봇종합학술대회)); Development of an In-situ Underwater Microscope Using Flow-blocking Mechanism for Robust Plankton Observation (ICCAS2023); 무인자율 수중로봇을 활용한 해저면 해양쓰레기 탐지 시스템 (ICROS2023); 수중터널의 실해역 환경에 강인한 멀티 수중 로봇 시스템의 제어기 구현 (2023 전산구조공학회 정기학술대회); Seabed Object's Height Estimation Method Utilizing Tilt Angle Changes of Imaging Sonar (2023 IEEE International Symposium on Underwater Technology, UT 2023); Seabed Object’s Height Estimation Method Utilizing Tilt Angle Changes of Imaging Sonar (UT23(International Symposium on Underwater Technology)); Neural Network based CPG Control Method of Undulating Fin in Underwater Biomimetic Robot (UT23(International Symposium on Underwater Technology)); 수동형 조인트 기반 생체모방 수률양용 로봇의 개발 (Development of Passive Joint based Sea-land Biomimetic Amphibious Robot) (2023 KRoC (제18회 한국로봇종합학술대회)); 수동 조인트 기반 연결형 벽 이동 로봇의 개발 (Development of Passive Joint-Based Connection Type Wall-Climbing Robot) (2023 KRoC (제18회 한국로봇종합학술대회)); 고신뢰도 수중 이미지 소나 시뮬레이터를 이용한 수중로봇의 학습기반 물체탐지 기법(High Reliability Underwater Image Sonar Simulator based Learning Method for Object Recognition Using AUV) (2023 KRoC (제 18회 한국로봇학회))
